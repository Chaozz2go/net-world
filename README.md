# NET//WORLD browser preview

Ein statischer Konzept-Prototyp für GitHub Pages. Die Netzwerkgeräte und Terminalbefehle sind vollständig simuliert; der Prototyp verbindet sich nicht mit echten Systemen und enthält noch keinen persistenten Multiplayer-Server.

## Live-Vorschau

https://chaozz2go.github.io/net-world/

## Lokal ansehen

`index.html` direkt im Browser öffnen.

## Auf GitHub Pages veröffentlichen

Die Datei `index.html` kann im Stammverzeichnis eines Repositorys liegen. In den Repository-Einstellungen unter **Pages** die Veröffentlichung aus dem gewünschten Branch und `/ (root)` aktivieren. Für den ersten Prototyp werden weder Docker noch ein Build-Schritt benötigt.

## Vorschau-Befehle

- `help`
- `ip route`
- `scan`
- `traceroute RELAY-04`
- `ssh MA-MAN-02`
- `show logging`
- `report`

Die Beispielmission ist ein UI-/Gameplay-Prototyp. Accounts, Spielstand, gemeinsame Welt, Koop und PvP brauchen später ein serverseitiges Backend.
